# Segurança

Achou uma vulnerabilidade (por exemplo no acesso pelo celular, no Hub ou no controle do PC)? **Não abra uma issue pública.** Use **Security › Report a vulnerability** neste repositório (aviso privado).

Inclua a versão, como reproduzir e o impacto. Responderemos assim que possível.

Se você expôs uma chave de API ou token sem querer, **revogue-a** no serviço de origem. Apagar o commit não basta.
