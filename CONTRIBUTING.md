# Contribuindo

1. Faça um fork e crie uma branch.
2. `npm ci` e `npm start` para rodar; `npm test` antes de enviar.
3. Mantenha a mudança pequena e descreva o que testou no Pull Request.
4. Não inclua `config.json`, chaves, tokens, `.userdata/` nem backups `.yorubackup`.
5. Mudanças visíveis ao usuário entram no `CHANGELOG.md`.

A versão em `package.json` precisa bater com o título do `README.md` (`# Yoru vX.Y.Z`); os testes conferem.
